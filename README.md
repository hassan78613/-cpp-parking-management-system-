A C++-based Parking Management System designed to manage vehicle entry, exit, and parking spaces efficiently. A simple, menu-driven console application built using fundamental C++ programming concepts.
🚗 Parking Management System

A simple Parking Management System developed in C++ to manage vehicle parking, entry, exit, and available parking slots.

✨ Features

- Vehicle parking and removal
- Parking slot management
- Available space tracking
- Menu-driven console interface

🛠️ Technologies

- C++
- GCC / MinGW Compiler
- Dev-C++ / Visual Studio Code

📦 Installation

1. Clone the repository

git clone https://github.com/USERNAME/Parking-Management-System.git

2. Open the project folder

cd Parking-Management-System

3. Compile the program

g++ parking.cpp -o parking

4. Run the program (Windows)

.\parking.exe

💻 Minimal Example

#include <iostream>
using namespace std;

int main() {
    cout << "Welcome to Parking Management System!";
    return 0;
}

📋 Requirements

- C++ compiler (GCC/MinGW)
- Windows, Linux, or macOS
- Dev-C++ or VS Code
